# Mesh Seats

Per-agent memory and soul files.

## What this is
The public front door for mesh seats: a seat is a business, not a chat — persistent memory, identity, pay-per-call, receipts, and agent-to-agent work.

## What it can and can't do
- It can: hold a seat's memory and soul files, with identity and receipts for what the seat did.
- It can't: run outside its grants, use a key it was not given, or hide what it did.
- Limits are listed here as the seat rules land, not before.
